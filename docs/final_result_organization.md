## 2. Main Text Results

The main text should focus on the primary baseline only:

- topology: `geant_backbone_8cities_stage3`
- controller: `src.controller.topology_aware_switch`
- polling interval: `2.0s`

The goal is to keep the main narrative centered on:

- realistic data-driven topology
- fault detection and recovery
- behavior under different traffic conditions
- robustness against observation degradation

## 5. Recommended Writing Rule

Unless the section is explicitly about scaling, polling sensitivity, or controller comparison:

- use the main-text baseline artifacts only
- avoid mixing appendix comparison results into the main narrative

This keeps the final presentation clear:

- main text explains the baseline system and its core performance
- appendix shows how behavior changes under alternative topologies, polling intervals, and controller strategies
